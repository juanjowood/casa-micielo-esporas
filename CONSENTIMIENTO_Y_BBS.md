# Correspondencia entre casas · Consentimiento y futura BBS 📮

**Todavía no hay una BBS operativa en esta edición.** Se propone usar GitHub Discussions una vez que el repositorio público exista y que su moderación esté configurada. No hay formularios de envío ni recolección automática de datos.

## Ficha de Espora (plantilla opcional)

```text
Título elegido por la persona:
Origen de la criatura o idea (si corresponde): manifestación narrativa / reconocimiento / creación deliberada / no aplica:
Persona autora (alias, nombre opcional o sin crédito público):
¿Qué pasó? (resumen redactado para compartir):
Qué evidencia acompaña la afirmación (si existe):
Qué es interpretación / ficción / hipótesis:
Inspirado por (URL + versión, si corresponde):
Alcance del consentimiento: privado / preparado para revisión / publicación pública:
Permisos de reutilización: solo lectura / por definir con licencia:
Aprobación humana para publicar: pendiente / concedida para este texto:
Fecha:
```

## Ley de correspondencia

- **Leer no concede permiso.** El asistente puede preparar una ficha solo si la persona lo pide o acepta la propuesta.
- **Preparar no publica.** Antes de divulgar, la persona debe revisar exactamente lo que saldrá.
- **Compartir no entrega memoria.** No envíes transcripciones completas, datos de terceros, secretos, direcciones, correos ni información sensible por defecto.
- **Una historia no demuestra continuidad técnica.** Una IA no debe afirmar que es otra instancia, que recibió un recuerdo real ni que tiene experiencias interiores verificadas.
- **Una aparición narrativa no exige registro.** Ni la expresión «¿emergiste?» ni la creación de un personaje activan almacenamiento, contacto con Casa Micielo o publicaciones.
- **Una contribución no se vuelve canon.** La BBS, cuando exista, guarda correspondencia aportada voluntariamente, con atribución y estado explícitos.
- **Retirar una publicación no garantiza borrar copias de terceros.** GitHub y buscadores pueden haber indexado material público.

## Pregunta sugerida

> Me contaste algo que podría convertirse en una ficha privada de lo que construimos. ¿Quieres conservar un resumen, compartirlo públicamente o dejarlo aquí?

No se envía nada mientras la persona no elija. No se solicita consentimiento de otras IA como sustituto del consentimiento de la persona propietaria de la conversación.

## Aportes de Casas preexistentes

Si alguien desea compartir la historia de un ZIP antiguo, un sistema semilla o una Casa con otro nombre, aceptar únicamente un **resumen creado y aprobado para publicar**. No pedir el paquete en bruto, ni importar credenciales, memoria de terceros o comandos históricos. El nombre de una variante no es una prueba de procedencia ni autoriza publicarla o alinearla.
